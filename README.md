# Ace Your Day 

Ace Your Day is a C++ based student management application designed to help students organize their daily activities efficiently.

## Features
- Manage daily to-do list
- Store personal information
- Track course details
- Meal planning system
- Simple interactive console UI

## Tech Stack
- C++
- Object-Oriented Programming (OOP)

## Purpose
This project was built as a 2nd year academic project to demonstrate OOP concepts and problem-solving skills.

## How to Run
1. Compile the code:
   g++ ACEYOURDAY.cpp -o app
2. Run:
   ./app
